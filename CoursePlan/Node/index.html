Learning Outcomes

Skills students should gain after completing the course.

01

Node.js Runtime

Explain how Node.js runs JavaScript on the server and how it differs from the browser.

02

Modules and NPM

Structure projects with CommonJS modules and manage dependencies using npm.

03

Files and Data

Read, write, and stream files and store data as JSON files or in a database.

04

Web Servers and REST APIs

Build HTTP servers with Express and design REST APIs with correct status codes.

05

Authentication and Security

Validate input, hash passwords, issue JWTs, and apply basic security middleware.

06

Testing and Deployment

Write unit and API tests, debug with Node tools, and deploy projects to hosting platforms.
