Week Topics Practical Work

Learning Outcomes

Skills you should gain after completing this course.

01

CSS Fundamentals

Understand CSS syntax, selectors, properties, values, and cascading rules.

02

Visual Styling

Apply colors, backgrounds, fonts, text styles, borders, and shadows.

03

Layout Design

Use the box model, Flexbox, Grid, and positioning to arrange content.

04

Responsive Websites

Create layouts that adapt to desktop, tablet, and mobile screens.

05

Animations and Effects

Build smooth transitions, transforms, and keyframe animations.

06

Professional Styling

Organize CSS, use variables, debug styles, and improve accessibility.
